# Osama Abdul Mazid — Groom Portfolio

A mobile-first, GitHub Pages-ready marriage/groom profile.

## Add your photos
Replace the visual placeholder boxes in `index.html` with your own images, preferably compressed WebP/JPG files inside `assets/`.

Suggested files:
- hero.webp
- portrait-01.webp
- portrait-02.webp
- travel-01.webp
- travel-02.webp
- lifestyle-01.webp
- lifestyle-02.webp

## Publish
Upload `index.html`, `style.css`, `script.js`, and `assets/` to a GitHub repository and enable GitHub Pages.

Before publishing, replace `YOUR-EMAIL@example.com` with the contact method you actually want to expose.
