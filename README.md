# Osama Abdul Mazid — Groom Profile

Warm, cinematic, mobile-first matrimonial portfolio.

## Before publishing
1. Replace every `portrait-placeholder` with your real photographs.
2. Replace `YOUR-EMAIL@example.com` in `index.html`.
3. Review all personal facts before making the repository public.
4. Keep exact home address, private family names, documents and sensitive contact details off the public site.

## GitHub Pages
Upload the files to your `groom-profile` repository and enable Pages from Settings → Pages → Deploy from branch → main → /root.
